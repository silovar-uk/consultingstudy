# 資格・実務ラボ｜調査・設計・実装・検証（2026-10-19）

## この改修で解く問題
「どの資格を取るか」より「限られた時間で、どんな実務判断ができるようになるか」を優先する。既存の43章教材は維持し、資格試験の公式出題範囲を参照した独立の実務学習導線を追加する。

## 三者の役割
- **前提批判担当**：資格が実務の代替になるという前提を疑う。受験せず学習する・成果物を作る・受験を延期する選択を常設。
- **一次情報調査担当**：2026年7月改訂のPMP、2026年度と2027年度が異なる簿記の出題区分、2027年度に変更予定のIPAなどを公式発表で照合。問題は独自制作し公式問題を転載しない。
- **実行設計担当**：「今日の一手」をトップへ置き、選択した領域の講義・正誤・復習・成果物を少ない操作でつなぐ。端末内保存、旧版ログの維持、JSONバックアップを設計。

## 守破離によるUXの判断
- **守**：既存のホーム・43章・財務演習・弱点マップ・成果物ライブラリは削除しない。既存 `data.js` と `app.js` の基本の保存形式を維持。
- **破**：章の大きな地図からではなく「今日→教材→クイズ→成果物→資格の判断」で操作できる。学習の目的と成果を一画面から理解可能に。
- **離**：資格の合否・連続ログイン日数を成功指標にせず、実務用の成果物の質と第三者のフィードバックを中心にする。取得しない選択肢も選べる。

## 追加実装
- 7領域：PMP（2026年版）、簿記2級への橋渡し、統計検定2級への橋渡し、中小企業診断士の基礎、ITストラテジストの基礎、ECBAの基礎、PSM Iの基礎。
- 21単元。各単元に「なぜ必要か」「重要概念3個」「具体例」「実務成果物の課題」「自己点検3項目」「公式出典」を設定。
- 42問の独自四択。各問に正解・解説・よくある誤解を設定。
- 7領域を1問ずつ問う出発点の診断。資格適性や合格可能性を測るものではない。
- 誤答は原則1日後、正答は3→7→14日後に復習対象とする簡易間隔復習（学術的な最適間隔という主張ではない）。
- 12週間の計画（週2〜3時間を仮定）。達成チェックは自己申告。期限強制なし。
- 実務メモの保存・セルフチェック・テンプレートのコピー・Markdown書き出し。
- URL `#/cert-lab` で直接表示。学習状態は既存 `state.certLab` に格納し、従来のJSONバックアップに含める。
- GitHub Pages対応。ログイン、外部API、ビルド環境、秘密鍵は不要。

## ユーザーの操作
1. ホームの「資格・実務ラボ」かサイドバーを開く。
2. 領域を選ぶ。迷ったら7問診断を受ける。
3. 今日の講義を開き、例題と概念を読む。
4. その単元の独自クイズを2問解く。回答直後に解説を読む。
5. 成果物タブで実務メモを作り、自己点検して保存する。
6. 後日「復習」へ戻り、定着を試す。
7. 12週間で「受験する・学習だけする・成果物を優先する」を選び直す。

## 第一次調査→追加調査→再調査
- 第一次調査で既存サイトのコードと利用導線を検証。現行版は学習43章と財務重点のドリルを持ち、資格別の計画は独立していなかった。
- 追加調査計画：公式試験出題範囲と更新時期、実務への応用例、合格と能力向上の違いを確認。
- 再調査で公式資料を参照。PMP 2026はPeople 33% / Process 41% / Business Environment 26%。簿記は2026年度と2027年度で異なる出題区分が適用。統計検定2級は大学基礎統計、ECBAは9領域の新しい試験範囲を参照。
- 注意：求人45件のサンプル調査、第三者による実務成果物評価は未実施。ランキングや合格予測は表示しない。

## 技術・安全・制約
- `cert-lab-data.js` はコンテンツデータ。既存教材に上書きしない。
- `cert-lab.js` は画面描画とイベント処理。学習ログは既存 `state` の配下へ保存され、外部送信しない。
- `cert-lab.css` は固有クラスでスコープ化。iPhone表示、ライト・ダーク・文字サイズ、操作対象44px前後を考慮。
- 入力文はHTMLエスケープ。メモ入力には業務上の秘密や個人情報を記載しないことを明示。
- 本版は公式試験対策の網羅的講座でも、PMPの研修時間を満たす講座でもない。実試験までには公式教材・最新受験案内で学習範囲を補う。
- 復習計算は単純な規則。理解度の科学的測定や合格確率を表示しない。
