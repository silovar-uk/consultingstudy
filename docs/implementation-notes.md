## 現時点で「モック / 初期版」に留めたもの

```text
- 全42章の本文：章立てはあるが、詳細本文入りは財務中心の8章
- 問題数：動作確認用の3問
- 自己採点：最終判定は学習者が行う方式
- 振り返り：ローカルのルールベース生成。AI API未接続
- 企業データ：架空の小売企業。EDINET等から自動取得しない
- 成果物：カード表示とメモ保存が中心。PDF/PPTX出力未実装
```

## Phase 2で優先する実装

1. **財務Gateを先に完成させる**
   - Gate 0〜6へ各10問以上
   - 計算 / 読解 / 仮説 / 総合演習を混ぜる
   - 各章の成果物テンプレートを追加

2. **コンテンツを `data.js` から分離する**
   - `content/chapters/finance/*.json`
   - `content/questions/finance/*.json`
   - 本文が長くなったらMDX

3. **誤答ログから出題を変える**
   - 同じ誤答タグが3回続いたら前提ドリルへ戻す
   - 正答・高自信ならスペシャル問題へ
   - 低自信の正答には、形式を変えた再出題

4. **AIレビューを追加する**
   - 回答を「観察 / 解釈 / 仮説 / 確認事項」でレビュー
   - 事実と仮説の混同、分母・期間漏れを指摘
   - 次の30分メニューを個別に出す

## AI接続時の注意

```text
- APIキーをGitHub Pagesのクライアントコードに直接書かない
- APIはCloudflare Workers / Vercel Functions / Supabase Edge Functions等を介す
- 実在企業の数値は、出所・公表日・資料名を必ずユーザーに残させる
- 機密情報・未公開情報をAIレビューに送らない注意をUIで明示する
```
