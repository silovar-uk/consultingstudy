# Guided Journey｜学習ループ仕様

更新日: 2026-07-10

## 役割分担

- Journey: 今日の一歩を順番に学ぶ主導線
- Atlas: 43章を自由に参照する教科書
- Studio: 数字、メモ、成果物をつくる場所
- Review: 誤答、弱点、過去内容を思い出す場所

## 6ステップ

### 1. 予想する

正解を見る前の直感を選ぶ。選択後も失点は付けない。

### 2. ケースを動かす

分類、比較、並べ替えなど、章に合う操作を行う。正しい組み合わせになるまで次へ進めない。

### 3. 自分の言葉にする

観察した内容や判断理由を書く。必要な長さを満たすまで次へ進めない。

### 4. 型につなぐ

初心者向けの橋渡し、教科書の言葉、基本の型、例題、よくある失敗、章に接続したコラムを読む。

### 5. 思い出す

資料を閉じた前提で2問へ回答する。2問とも正解するまで成果物へ進めない。

### 6. 成果物にする

実務へ持ち出せる最小成果物と自信度を残す。完了時に成果物ライブラリへ自動保存する。

## 完了条件

- 予想を選択済み
- ケース操作を正しく完了
- 自分の言葉で必要文字数を入力
- 想起問題2問に正解
- 最小成果物を入力
- 自信度を記録

チェックボックスによる自己申告だけでは完了にしない。

## コラム

コラムは任意の息抜きではなく、本章の理解を別角度から補強する幕間とする。

- 現場の一幕
- 失敗の解剖
- 商売のからくり
- 道具と用語の歴史
- スポーツ・エンタメで考える

必ず`takeaway`を一文で付ける。実在の出来事や数値を扱う場合は`sources`へURLを追加する。
