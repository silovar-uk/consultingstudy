# Consulting Study｜秘書検定を「対人判断の実務力」として統合（2026-10-20）

## エグゼクティブサマリー

**既存7資格を8資格に増やすことが目的ではない。** 秘書検定2級の公式5領域を実務能力として解釈し、PMO・業務分析・財務と結びつく「相手を支え、正しく情報を伝え、権限者へ判断をつなぐ」という能力を補完する。

- 既存の43章・7領域21単元・90問を保存。
- **3単元、独自の四択9問、異形式3問**を追加。全体で8領域24単元、102問（従来の90問＋12問）。別管理の財務・統計・PMOのA/B/C評価9問およびPMO実務判断2ケースは102問に含まない。
- ラボの主要4タブは増やさない。秘書検定は学習領域の選択肢へ追加。PMO ↔ 秘書検定の横断練習リンクを両方の学習プランに設ける。
- 正答と解説はオリジナル。**試験問題の転載なし**。基礎の一部を扱うもので、2級の完全対策・合格可能性の診断とは扱わない。
- 公式の5領域（理論3・実技2）を「範囲と対応」で確認できる。関連する既存Atlasの章も直接開ける。

## 1. 前提を疑う担当：検討した代替案

| 案 | 長所 | 主な弱点 | 結論 |
|---|---|---|---|
| A：秘書検定を一資格として独立追加 | 受験対策の見通しが良い | 「秘書の仕事」だけに閉じ、既存PMO/資料づくりとの重複が大きい | 資格トラックのみでは不十分 |
| B：既存のPMP教材に数行を足すだけ | 導入は早い | 敬語・一次応答・補佐権限を整理して学習できない | 不採用 |
| **C：3つの対人・実務支援能力として統合** | 5領域の所在を明確にしたまま業務場面へ応用できる | 試験全体の網羅性はない | **採用** |
| D：既存の外部教材を紹介するだけ | 実装量が少ない | 既存の演習・復習履歴と連携しない | 公式対策が必要な場合は併用 |

### なぜ3単元なのか

1. **機密・先回りと職務の境界**：資質＋職務知識。責任者不在、情報共有、承認のケース。
2. **敬語・傾聴・報告**：マナー・接遇。一次応答、苦情、要点報告のケース。
3. **会議・文書・日程**：技能＋一般知識。会議延期、版管理、経営用語を扱うケース。

5つの試験領域を消してまとめたのではなく、**公式区分を問題のメタデータとして保持し、業務上必要な行動別に教材を再編**した。

## 3. 次のリサーチ計画：何を生データで確認するか

「要約記事による難易度」ではなく、次の原資料を優先する。

1. **公式審査基準**：2級の各要求事項の原文を全件照合し、今回の3単元が扱わない項目を列挙。出題比率を推測しない。
2. **公式公開例題の出題パターン・解答例**：敬語、複数条件下での応対判断、記述の採点条件を確認。ただし著作権保護された問題の転載はしない。
3. **実利用者の作業ログ（本人提供・明示同意のみ）**：練習開始までの操作数、旧7領域からの再開動作、記述答案の保存失敗、PMOからの行き来、最初の回答と復習の差。
4. **実務レビュー**：秘書業務・総務・コンサルの経験者に、正答の一意性・敬語・業務判断・機密の扱いを別々に査読してもらう。

### Value of Information による優先順位

- P0：敬語や機密対応の誤答が誤学習を生むか → **他者の独立査読**が必要。重大な誤りが見つかれば当該設問を止める。
- P0：旧7領域の学習ログが保持され、秘書検定の回答が混ざらないか → **ソース検証と操作テスト**。
- P1：多形式の演習を実際に使ってもらえるか → **タスク完了率、入力負荷、所要時間**。
- P2：秘書検定2級の合格を目標にする必要があるか → **本人の受験目的と実務ニーズの比較**。必要になるまで試験準拠機能は拡張しない。

## 4. 再リサーチ・反証：最初の考えを変えたところ

### 仮説「敬語を正しく覚えるだけで実務対応力が向上する」

**反証**：丁寧に話せても、権限のない約束・不必要な情報共有・報告の未完了があれば実務リスクが増える。

**更新**：対人表現に加え、事実、許可、期限、次の連絡をセットで問う。丁寧さだけでは正答にしない。

### 仮説「秘書検定は秘書職だけの資格」

**反証**：公式5領域のうち多くは社内外の連絡・資料管理・一般的な経営知識・判断を含み、業種横断的な要素がある。ただし、全職種で同じ慣習が最適という保証はない。

**更新**：業務場面をコンサル・PMOへ翻訳し、相手の背景や組織のルール・文化を無視する画一的な応対を押し付けない。客先の方針や安全・機密ルールが優先される条件を明示する。

### 仮説「5領域なのだから5つの画面を増やす」

**反証**：ナビゲーションの選択肢と重複教材が増え、既存UXの簡素化方針に反する。

**更新**：学習UIは既存の4タブのまま、3単元に集約。公式領域との対応は「範囲と対応」に格納する。

- `cert-lab-secretary-deep.js`：秘密情報の共有判断（複数選択）、会議の段取り（順序）、顧客への一次応答（記述・自己点検）。

## 6. 外部に妥当性を確認するには

自動テストは「正答キーが4択の範囲にある」「答案と採点処理が一致する」「保存が動く」ことまで。**正答が適切な応対かどうかは別途検証が必要**。

受入の計画：
- 2級の公式審査基準の全項目と今回の5領域対応を原文比較する。
- ビジネスマナーの専門家と、対人対応を行う実務者がそれぞれ独立に査読する。
- 尊敬語・謙譲語の場面を異なる立場・文化・組織規定で比較し、唯一の言い回しを押し付けない。
- iPhone Safariの実機で、学習領域切り替え、記述中のキーボード、スクロール、JSON保存と復元を検証する。
- 学習効果を主張する場合は、初見の別ケース・遅延評価・第三者採点に基づく。単なる問題数増・操作テスト成功では判断しない。

## 7. 最後の投資判断

**今実装する**：公式5領域の所在が分かる小規模な教材と、既存PMOへつながる練習。

**追加調査後に判断**：本格的な2級模擬試験・敬語表現の大量問題集・面接対策・学習成果の自動採点。

**しない**：公式合格率の根拠のない予測、機密情報のクラウド転送、AIによる記述の根拠なし採点、主要タブの増設。

設計目的は資格の数を増やすことではなく、**「正しく考えたことを、相手が安全に判断できる形で伝える」**能力の練習機会をつくること。
